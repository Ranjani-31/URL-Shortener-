# URL-Shortener
## 📌 Overview

- The URL Shortener allows users to:

- Convert long URLs into short links

- Access original URLs using shortened codes

- Track basic usage (optional)

- Improve link sharing and readability

- This project demonstrates backend logic, database design, and REST API concepts commonly used in real-world systems.

## ✨ Features

- Generate short URLs from long URLs

- Redirect short URLs to original URLs

- Unique short code generation

- URL validation

- Duplicate URL handling

- Optional click count tracking

- RESTful API design

- Error handling for invalid or expired links
